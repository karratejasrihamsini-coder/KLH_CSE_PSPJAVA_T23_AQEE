Abstract:  
The Adaptive Quiz & Exam Engine is a Java-based application designed to conduct interactive quizzes and examinations.The system allows users to answer multiple-choice questions and receive a score based on 
their performance. The quiz can adapt the difficulty of questions according to the user's answers. The project will be developed using Java concepts such as problem solving, algorithms, flowcharts, conditional 
statements, loops, switch statements, arrays, methods, and user input. The system will provide a simple menu-driven interface where users can start a quiz, answer questions, view their scores, and exit the 
application.
